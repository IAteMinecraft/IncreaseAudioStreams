# Ever wanted to have **more than 8** Jukeboxes playing at once?

---
This is a simple mod that increases Minecraft's hard limit of eight (8) Audio Streams to 32.

Audio Streams are, at its simplest, audio files that are getting played. Audio streams are not Sound Effects, those are different, Audio Streams (in the vanilla game) are only really created by Jukeboxes, but in the modded game, it gets a lot crazier!

This mod was primarily created because I wanted to give my base a full "Surround Sound" setup with ComputerCraft: Tweaked, and was very disappointed when it didn't work,  
but now it does :)

---  

The reason (as far as I know) that Mojang does not already do this, is that when there are too many Audio Streams, it can lag the server quite a bit, as the server has to process all of the audio streams.

---

You may use this in any modpack
